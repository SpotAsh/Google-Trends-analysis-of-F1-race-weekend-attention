# f1-economic-anomalies

Penn State DAAN 545 final project

# Make sure pip is up to date

- python -m pip list --outdated

# How to activate Venv

- python -m venv .venv
- run this command in terminal before starting work: .venv\Scripts\Activate.ps1
  - if scripts doesn't show up in .venv, remove venv cleaning and redownload

# Now download all the reqs

- pip install -r requirements.txt
- then check if everything is downloaded: pip list
